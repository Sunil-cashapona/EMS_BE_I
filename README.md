# Employee Management System

Project folder structure for FastAPI & Python.

## Database setup

This project connects to PostgreSQL using the values in `.env`. Copy
`.env.example` to `.env` and set `DATABASE_PASSWORD` to the password for the
PostgreSQL user. The default connection is:

- Host: `localhost`
- Port: `5432`
- Database: `postgres`
- User: `postgres`

Install dependencies with `pip install -r requirements.txt`.
